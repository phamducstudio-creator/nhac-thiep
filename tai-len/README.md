# Tải nhạc CHUNG lên đây

Bấm **Add file → Upload files** (hoặc mở thẳng https://github.com/phamducstudio-creator/nhac-thiep/upload/main/tai-len),
chọn file nhạc (mp3, m4a, wav… — tối đa 25 MB/file khi tải bằng trình duyệt) → bấm nút xanh **Commit changes**.

Khoảng 1–3 phút sau bài có trong kho (list.json), máy tự xoá file gốc ở đây. **Tên bài = tên file** (máy tự bỏ chữ rác
kiểu "y2mate.com", "(Official MV)").

Nhạc CHUNG = khách được chọn ở thiệp mẫu, form đặt thiệp và bảng nhạc của mọi thiệp. Bài hát có bản quyền nên bỏ vào
thư mục **rieng/** (không hiện công khai).
