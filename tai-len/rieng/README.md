# Tải nhạc RIÊNG lên đây

https://github.com/phamducstudio-creator/nhac-thiep/upload/main/tai-len/rieng → chọn file → **Commit changes**.

Nhạc RIÊNG = chỉ phát ở thiệp nào được chọn bài này (trong bảng sửa thiệp → Nhạc nền), không hiện ở trang bán thiệp,
thiệp mẫu hay thiệp của cặp khác. Nên dùng cho bài hát có bản quyền và bài riêng của từng cặp.
