# Lệnh cho bài đã tải lên (máy đọc, làm xong tự xoá)

Trang quản lý nhạc (https://www.phamducstudio.vn/quan-ly-nhac.html) tạo sẵn các file này — anh chỉ bấm **Commit changes**:

- `go-<mã bài>.txt` → gỡ bài khỏi kho (hoặc bỏ 1 mục báo lỗi)
- `doi-ten-<mã bài>.txt`, nội dung = tên mới → đổi tên bài

Chỉ áp cho bài tải thẳng lên GitHub (mã bắt đầu bằng `t`). Bài từ Google Drive thì đổi tên / xoá ngay trên Drive.
